# US-406: Edit Custom Challenge

## User Story
As a challenge creator,
I want to edit my custom challenge,
So that I can adjust tasks and schedules as needed.

## Acceptance Criteria
- [ ] AC-1: Creator can edit challenge title/description
- [ ] AC-2: Creator can add new tasks
- [ ] AC-3: Creator can edit existing tasks
- [ ] AC-4: Creator can change task schedules
- [ ] AC-5: Creator can delete tasks
- [ ] AC-6: Changes are saved immediately
- [ ] AC-7: Non-creators cannot edit

## User Types
- Registered User (Challenge Creator)

## Priority
Medium
