# US-104: Goal Visibility

## User Story
As a goal owner,
I want to control who can see my goal,
So that I can choose between public, friends-only, or private visibility.

## Acceptance Criteria
- [ ] AC-1: Goals can be set to public visibility
- [ ] AC-2: Goals can be set to friends-only visibility
- [ ] AC-3: Goals can be set to private visibility
- [ ] AC-4: Public goals visible to all users including guests
- [ ] AC-5: Friends-only goals visible to accepted friends only
- [ ] AC-6: Private goals visible to owner only
- [ ] AC-7: Coach can view participant goals regardless of visibility
- [ ] AC-8: Visibility can be changed after creation

## User Types
- Registered User (Goal Owner)
