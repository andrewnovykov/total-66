# US-611: Group Following

## User Story
As a registered user,
I want to follow groups,
So that I can see relevant goals and updates from group members.

## Acceptance Criteria
- [ ] AC-1: User can follow a group
- [ ] AC-2: User can unfollow a group
- [ ] AC-3: Group follower count updates
- [ ] AC-4: Group activity appears in feed
- [ ] AC-5: One-way follow relationship (no approval)
- [ ] AC-6: Guests cannot follow groups

## User Types
- Registered User

Medium
