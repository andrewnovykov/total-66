# US-400: Browse Challenges

## User Story
As a registered user,
I want to browse available challenges,
So that I can find structured programs to follow.

## Acceptance Criteria
- [ ] AC-1: User can access challenges page from navigation
- [ ] AC-2: Predefined (admin-created) challenges are listed
- [ ] AC-3: Challenges show title, description, and duration
- [ ] AC-4: Challenges are grouped by category (30-day, 90-day, custom)
- [ ] AC-5: User can filter challenges by duration
- [ ] AC-6: Join button is visible for available challenges

## User Types
- Registered User
