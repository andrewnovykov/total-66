# US-507: Track Participant Progress

## User Story
As a coach,
I want to see detailed progress for each participant,
So that I can provide targeted support.

## Acceptance Criteria
- [ ] AC-1: Coach can view individual participant detail
- [ ] AC-2: Progress percentage is displayed
- [ ] AC-3: Completed vs pending steps shown
- [ ] AC-4: Last activity date visible
- [ ] AC-5: Commitment heatmap displays activity patterns
- [ ] AC-6: Coach cannot edit participant progress

## User Types
- Coach

## Priority
Medium
