# Feature Priority List

## MUST HAVE (MVP — Build First)
- Auth + roles (guest/user/coach/admin)
- Home (Trending goals, Popular groups, User spotlight)
- Goals: create/edit/delete + phases/steps + statuses + visibility
- Challenges: admin predefined creation, user join predefined, user-created with tasks + schedules
- People directory + profile + commitment chart
- Social: follow/unfollow users, friend requests, follow goals
- Interactions: like/dislike + comments (goals + posts)
- My Goals dashboard (management)
- Categories admin CRUD
- 3 active items rule enforcement
- Coach Center: group goal templates + start + dashboard

## SHOULD HAVE (Phase 2)
- Personalized feed aggregation (“from followed users/goals”)
- Notifications (in-app/email): likes/comments/follows/coach nudges
- Better recommendations (people/goals/groups)

## NICE TO HAVE (Future)
- Messaging (coach ↔ participants)
- Monetization: paid coach programs, premium analytics
- Advanced analytics: goal completion predictions
