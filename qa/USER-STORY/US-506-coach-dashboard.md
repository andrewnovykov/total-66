# US-506: Coach Dashboard

## User Story
As a coach,
I want a dashboard showing all my group goals and participants,
So that I can monitor progress and identify issues.

## Acceptance Criteria
- [ ] AC-1: Dashboard shows list of group goals
- [ ] AC-2: Each group goal shows participant count
- [ ] AC-3: Can drill down to participant list
- [ ] AC-4: Per-participant: status, progress %, last activity
- [ ] AC-5: At-risk indicators for inactive participants
- [ ] AC-6: Overall group progress statistics

## User Types
- Coach
