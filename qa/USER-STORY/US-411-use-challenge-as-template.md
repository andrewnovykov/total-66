# US-411: Use Challenge as Template

## User Story
As a registered user,
I want to use an existing challenge as a template,
So that I can create my own version based on a proven structure.

## Acceptance Criteria
- [ ] AC-1: "Use as Template" button on completed challenges
- [ ] AC-2: Creates new custom challenge with copied structure
- [ ] AC-3: User can edit the copied structure
- [ ] AC-4: Original challenge is unchanged
- [ ] AC-5: New challenge starts fresh (no progress)
- [ ] AC-6: Counts as new active item

## User Types
- Registered User
