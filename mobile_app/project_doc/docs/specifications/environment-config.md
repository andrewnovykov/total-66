# Environment Configuration

## Environment Variables Reference

```bash
# ============================================
# Application
# ============================================
MIX_ENV=dev                          # dev | test | prod
PHX_SERVER=true                      # Enable Phoenix server (required for prod)
PHX_HOST=localhost                   # Hostname for URLs
PORT=4000                            # HTTP port

# ============================================
# Database
# ============================================
DATABASE_URL=ecto://postgres:postgres@localhost:5432/heads_up_dev
POOL_SIZE=10                         # Database connection pool size
ECTO_IPV6=false                      # Enable IPv6 for database connection

# ============================================
# Security
# ============================================
SECRET_KEY_BASE=                     # Generate with: mix phx.gen.secret

# ============================================
# Render.com Specific
# ============================================
RENDER_EXTERNAL_HOSTNAME=            # Auto-set by Render.com
DNS_CLUSTER_QUERY=                   # For distributed Elixir clustering

# ============================================
# Email Service (optional)
# ============================================
# MAILGUN_API_KEY=
# MAILGUN_DOMAIN=

# ============================================
# File Storage (future)
# ============================================
# S3_BUCKET=
# S3_REGION=
# S3_ACCESS_KEY_ID=
# S3_SECRET_ACCESS_KEY=
```

## Per-Environment Overrides

| Variable              | Development                      | Test                              | Production (Render)               |
| --------------------- | -------------------------------- | --------------------------------- | --------------------------------- |
| `MIX_ENV`             | `dev`                            | `test`                            | `prod`                            |
| `PHX_HOST`            | `localhost`                      | `localhost`                       | `RENDER_EXTERNAL_HOSTNAME`        |
| `PORT`                | `4000`                           | `4002`                            | `10000` (Render assigned)         |
| `DATABASE_URL`        | `ecto://postgres:postgres@localhost:5432/heads_up_dev` | `heads_up_test` | Render managed PostgreSQL |
| `POOL_SIZE`           | `10`                             | `schedulers * 2`                  | `10`                              |
| `SECRET_KEY_BASE`     | Hardcoded in dev.exs             | Hardcoded in test.exs             | Generated by Render               |
| `LOG_LEVEL`           | `debug`                          | `warning`                         | `info`                            |
| Bcrypt rounds         | Default (12)                     | `1` (fast tests)                  | Default (12)                      |

## Configuration Files

```
config/
├── config.exs      # Base configuration (all environments)
├── dev.exs         # Development environment
├── test.exs        # Test environment
├── prod.exs        # Production compile-time config
└── runtime.exs     # Runtime configuration (secrets from env vars)
```

### config.exs (Base)

```elixir
import Config

config :heads_up,
  ecto_repos: [HeadsUp.Repo],
  generators: [timestamp_type: :utc_datetime]

config :heads_up, HeadsUpWeb.Endpoint,
  url: [host: "localhost"],
  adapter: Bandit.PhoenixAdapter,
  render_errors: [
    formats: [html: HeadsUpWeb.ErrorHTML, json: HeadsUpWeb.ErrorJSON],
    layout: false
  ],
  pubsub_server: HeadsUp.PubSub,
  live_view: [signing_salt: "DS9ubxYu"]

config :heads_up, HeadsUp.Mailer, adapter: Swoosh.Adapters.Local

config :esbuild, version: "0.17.11"
config :tailwind, version: "3.4.3"
config :phoenix, :json_library, Jason

import_config "#{config_env()}.exs"
```

### runtime.exs (Production Secrets)

```elixir
import Config

if System.get_env("PHX_SERVER") do
  config :heads_up, HeadsUpWeb.Endpoint, server: true
end

if config_env() == :prod do
  database_url =
    System.get_env("DATABASE_URL") ||
      raise "environment variable DATABASE_URL is missing."

  maybe_ipv6 = if System.get_env("ECTO_IPV6") in ~w(true 1), do: [:inet6], else: []

  config :heads_up, HeadsUp.Repo,
    ssl: [verify: :verify_none],
    url: database_url,
    pool_size: String.to_integer(System.get_env("POOL_SIZE") || "10"),
    socket_options: maybe_ipv6

  secret_key_base =
    System.get_env("SECRET_KEY_BASE") ||
      raise "environment variable SECRET_KEY_BASE is missing."

  host = System.get_env("PHX_HOST") || System.get_env("RENDER_EXTERNAL_HOSTNAME") || "example.com"
  port = String.to_integer(System.get_env("PORT") || "4000")

  config :heads_up, :dns_cluster_query, System.get_env("DNS_CLUSTER_QUERY")

  config :heads_up, HeadsUpWeb.Endpoint,
    url: [host: host, port: 443, scheme: "https"],
    http: [ip: {0, 0, 0, 0, 0, 0, 0, 0}, port: port],
    secret_key_base: secret_key_base
end
```

## Secret Management Strategy

| Environment | Method                              |
| ----------- | ----------------------------------- |
| Local dev   | Hardcoded in `dev.exs` (gitignored values only) |
| CI/CD       | GitHub Actions secrets              |
| Staging     | Render.com Preview Environments     |
| Production  | Render.com Environment Variables    |

**Rules:**
- `config/dev.exs` and `config/test.exs` use hardcoded values for local development
- Production secrets are **never** committed to version control
- `SECRET_KEY_BASE` is auto-generated by Render.com
- `DATABASE_URL` is auto-injected from Render PostgreSQL service
- All secrets use minimum required permissions

## Render.com Environment Variables

Configured in `render.yaml`:

| Variable           | Source                              | Description                        |
| ------------------ | ----------------------------------- | ---------------------------------- |
| `DATABASE_URL`     | `fromDatabase: heads_up_db`         | Auto-injected PostgreSQL connection string |
| `SECRET_KEY_BASE`  | `generateValue: true`               | Auto-generated secure secret       |
| `POOL_SIZE`        | `value: "10"`                       | Database connection pool size      |
| `PHX_SERVER`       | Implicit (Docker CMD)               | Enabled by start command           |
| `PORT`             | Render-assigned                     | HTTP port (typically 10000)        |
| `RENDER_EXTERNAL_HOSTNAME` | Auto-set by Render           | Public hostname for the service    |

## Feature Flags

| Flag Name     | Default (dev) | Default (prod) | Description                        |
| ------------- | ------------- | -------------- | ---------------------------------- |
| `dev_routes`  | `true`        | `false`        | Enable dev routes (dashboard, mailbox) |

**Feature flag system:** Elixir Application environment (`Application.compile_env/3`)

```elixir
# Check at compile time
if Application.compile_env(:heads_up, :dev_routes) do
  # Dev-only routes
end

# Check at runtime
Application.get_env(:heads_up, :dev_routes, false)
```

## Configuration Validation

Phoenix/Elixir validates required environment variables at application startup via `runtime.exs`:

```elixir
# Fail fast if required vars are missing
database_url =
  System.get_env("DATABASE_URL") ||
    raise """
    environment variable DATABASE_URL is missing.
    For example: ecto://USER:PASS@HOST/DATABASE
    """

secret_key_base =
  System.get_env("SECRET_KEY_BASE") ||
    raise """
    environment variable SECRET_KEY_BASE is missing.
    You can generate one by calling: mix phx.gen.secret
    """
```

**Pattern:** Required variables raise at startup; optional variables have defaults.

## Database Configuration by Environment

| Environment | Database Name                      | Connection                         |
| ----------- | ---------------------------------- | ---------------------------------- |
| Development | `heads_up_dev`                     | `localhost:5432` (local PostgreSQL) |
| Test        | `heads_up_test#{partition}`        | `localhost:5432` with SQL Sandbox  |
| Production  | Render PostgreSQL                  | `DATABASE_URL` env var             |

```bash
# Development database commands
mix ecto.create          # Creates heads_up_dev
mix ecto.migrate         # Runs migrations
mix ecto.reset           # Drops, creates, migrates
mix run priv/repo/seeds.exs  # Seeds data

# Test database (auto-managed)
MIX_ENV=test mix ecto.create
MIX_ENV=test mix ecto.migrate

# Production (via Docker/Render)
/app/bin/migrate         # Runs during container startup
```
