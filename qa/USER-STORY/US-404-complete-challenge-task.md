# US-404: Complete Challenge Task

## User Story
As a challenge participant,
I want to mark tasks as completed,
So that I can track my progress through the challenge.

## Acceptance Criteria
- [ ] AC-1: User can mark scheduled task as complete
- [ ] AC-2: Completion is recorded with timestamp
- [ ] AC-3: Progress percentage updates
- [ ] AC-4: Completed tasks are visually distinguished
- [ ] AC-5: User can uncomplete a task (undo)
- [ ] AC-6: Daily completion tracking shows streak

## User Types
- Registered User (Challenge Participant)

## Priority
High
