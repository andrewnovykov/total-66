# Feature 4: Goals (Create + Feed + Detail)

## User Story
“As a user, I want to create goals with phases and steps so I can execute a structured plan and show progress.”

## Goal Type
- “Goal” (one of the two creation options: Goal vs Challenge)

## Goal Statuses
- Active
- Frozen (paused)
- Completed
- Failed

## Inputs
- Title (required)
- Optional description
- Image (optional; hidden if private)
- Category (required)
- Visibility (required): Public / Friends-only / Private
- Target date / due date (optional)
- Phases (optional but strongly encouraged)
- Steps inside phases (optional)

## Outputs
- Goal card on Goals page (with visibility applied)
- Goal detail page with its feed (posts)

## Rules
- Active goal counts toward “max 3 active items”
- Frozen/Completed/Failed do not count as active
- Visibility gates content display and interaction
