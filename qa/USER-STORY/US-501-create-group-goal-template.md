# US-501: Create Group Goal Template

## User Story
As a coach,
I want to create a group goal template,
So that I can define a structured program for participants.

## Acceptance Criteria
- [ ] AC-1: Coach can access template creation form
- [ ] AC-2: Coach must provide title (required)
- [ ] AC-3: Coach can add description
- [ ] AC-4: Coach must select a category
- [ ] AC-5: Coach can define phases
- [ ] AC-6: Coach can add steps within phases (at least 1)
- [ ] AC-7: Coach can set optional due date/duration
- [ ] AC-8: Template is saved as draft initially

## User Types
- Coach

High
