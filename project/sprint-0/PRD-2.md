### 0.2 Goals (Create + Detail + Feed)

#### Core Features
- [x] Goal creation with steps (flat structure - 20 steps max)
- [x] Goal visibility: public / private / friends-only
- [x] Goal detail page with progress tracking
- [x] Goal posts feed (5 post types: update, milestone, achievement, challenge, motivation)
- [x] Goal reactions - likes (with ownership prevention)
- [x] Goal post comments (with ownership controls)
- [x] Goal subscriptions (follow goal) with privacy enforcement

#### Additional Implemented
- [x] Step management (CRUD, reorder, toggle completion)
- [x] Post likes with ownership checks
- [x] Ownership controls for goals and posts
- [x] Image support for goals and posts
- [x] Subscription-based goal creation limits
- [x] Soft delete and freeze functionality
- [x] Goal failure tracking with reasons
- [x] Activity tracking for XP rewards

#### Deferred
- [ ] Dislike functionality (not required for MVP)
- [ ] Nested phases (flat steps sufficient for MVP)
