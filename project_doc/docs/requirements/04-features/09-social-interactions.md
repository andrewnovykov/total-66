# Feature 9: Social Interactions (Goals & Posts)

## User Story
“As a user, I want to like/dislike and comment on goals and goal posts so I can support others.”

## Interactions Supported
- Like/Dislike a Goal
- Comment on a Goal
- Like/Dislike a Goal Post (progress update)
- Comment on a Goal Post

## Rules
- Can’t like + dislike same item at once (toggle behavior)
- Visibility controls who can view/comment
- Guests cannot interact
