# US-301: Admin Category Management

## User Story
As an admin,
I want to manage goal categories,
So that users have organized options for categorizing their goals.

## Acceptance Criteria
- [ ] AC-1: Admin can view all categories
- [ ] AC-2: Admin can create new categories
- [ ] AC-3: Admin can edit category names/descriptions
- [ ] AC-4: Admin can delete unused categories
- [ ] AC-5: Cannot delete category with active goals
- [ ] AC-6: Categories appear in goal creation form

- Admin
