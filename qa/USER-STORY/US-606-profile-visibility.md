# US-606: Profile Visibility Settings

## User Story
As a registered user,
I want to control my profile visibility,
So that I can decide who can see my information and activity.

## Acceptance Criteria
- [ ] AC-1: User can set profile visibility to public, private, or friends_only
- [ ] AC-2: Public profile visible to everyone including guests
- [ ] AC-3: Private profile shows only basic info to non-friends
- [ ] AC-4: Friends-only profile fully visible to accepted friends
- [ ] AC-5: Visibility setting accessible from profile settings
- [ ] AC-6: Changes apply immediately

## User Types
- Registered User
