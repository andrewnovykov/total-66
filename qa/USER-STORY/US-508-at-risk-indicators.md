# US-508: At-Risk Participant Indicators

## User Story
As a coach,
I want to see which participants are at risk,
So that I can intervene before they fall behind.

## Acceptance Criteria
- [ ] AC-1: At-risk indicator shown for inactive participants
- [ ] AC-2: Definition: no activity for X days (configurable)
- [ ] AC-3: Visual warning (red/yellow indicator)
- [ ] AC-4: At-risk list accessible from dashboard
- [ ] AC-5: Count of at-risk participants shown
- [ ] AC-6: Indicator clears when participant becomes active

## User Types
- Coach
