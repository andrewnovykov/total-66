# US-002: User Login

## User Story
As a registered user,
I want to log in with my email and password,
So that I can access my goals and interact with the platform.

## Acceptance Criteria
- [ ] AC-1: User can access login page
- [ ] AC-2: User can log in with valid email and password
- [ ] AC-3: Navigation updates to show authenticated menu items
- [ ] AC-4: User is redirected to home page after login
- [ ] AC-5: Invalid credentials show error message
- [ ] AC-6: Session persists across page refreshes

## User Types
- Guest (becoming Registered User)

High
