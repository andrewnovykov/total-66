# Feature 7: People Directory + Profiles

## User Story
“As a user, I want to find people and see their consistency so I can follow disciplined creators.”

## People Page Elements
- Search
- Recommended people
- Following list
- “Top goal setters / most active” section

## Profile Page Elements
- Avatar, name, nickname
- Short bio
- Followers count, following count, friends count
- Level
- User goals list (visibility-based)
- Commitment chart (GitHub-style daily activity)
