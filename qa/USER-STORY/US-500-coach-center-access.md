# US-500: Coach Center Access

## User Story
As a coach,
I want to access the Coach Center,
So that I can manage group goals and track participant progress.

## Acceptance Criteria
- [ ] AC-1: Coach can see "Coach Center" in navigation
- [ ] AC-2: Coach Center page loads successfully
- [ ] AC-3: Non-coaches cannot access Coach Center
- [ ] AC-4: Coach Center shows overview of group goals
- [ ] AC-5: Quick actions for creating templates available

## User Types
- Coach
