# Feature 23: Activity Tracking & Analytics

## User Story
“As a user, I want to see my activity and progress over time.”

## Inputs
- Activity events (steps completed, posts created, challenges joined)

## Outputs
- Commitment chart (GitHub-style heatmap)
- Activity streaks (current/longest)
- Personal analytics (completion rates, trends)

## Rules
- Aggregations respect visibility rules
- Private activity never appears on public profiles
