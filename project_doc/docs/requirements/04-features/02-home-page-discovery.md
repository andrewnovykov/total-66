# Feature 2: Home Page Discovery (Trending Goals, Popular Groups, Spotlight Users)

## User Story
“As a user, I want to discover trending goals, groups, and active users so that I can join and follow inspiring progress.”

## Detailed Behavior
- User opens Home
- Sees 3 primary sections:
  - Trending Goals
  - Popular Groups
  - User Spotlight

## Outputs
- Goal cards with images + creator + status
- Group cards with counts (total goals, active goals)
- Spotlight user cards with avatar + name + level

## Rules
- Only public content appears for guests
- Friends-only content only for eligible viewers
