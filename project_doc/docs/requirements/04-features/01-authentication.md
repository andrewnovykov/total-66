# Feature 1: Authentication (Register / Login / Logout)

## User Story
“As a visitor, I want to register and log in so that I can create goals, follow people, and interact socially.”

## Inputs
- Email (required)
- Password (required)
- Username / nickname (required)
- Optional: profile photo, short bio

## Outputs
- Logged-in session
- Navigation updates (shows My Goals, etc.)
- Redirect to Home

## Rules
- Visitors cannot access My Goals or Coach Center or Admin pages
- Role determines which menus appear
