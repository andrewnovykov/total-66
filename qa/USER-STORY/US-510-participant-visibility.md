# US-510: Participant Goal Visibility

## User Story
As a participant,
I want to control the visibility of my goal instance,
So that I can choose who sees my progress outside the group.

## Acceptance Criteria
- [ ] AC-1: Participant can set visibility (public/friends/private)
- [ ] AC-2: Visibility applies to non-coach viewers
- [ ] AC-3: Coach always sees participant progress
- [ ] AC-4: Other participants may or may not see each other
- [ ] AC-5: Default visibility can be set by coach

## User Types
- Registered User (Participant)

## Priority
Low
