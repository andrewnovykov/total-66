# US-203: Post Likes

## User Story
As a registered user,
I want to like posts on goals,
So that I can show appreciation for progress updates.

## Acceptance Criteria
- [ ] AC-1: User can like posts on goals they can view
- [ ] AC-2: User cannot like their own posts
- [ ] AC-3: Like count displayed on post
- [ ] AC-4: User can unlike previously liked posts
- [ ] AC-5: Guests cannot like posts
- [ ] AC-6: Like/dislike toggle behavior

## User Types
- Registered User

Medium
