# Feature 17: Admin Dashboard & Management

## User Story
“As an admin, I want dashboards and tools to moderate content and manage users.”

## Admin Areas
- Analytics dashboard (users, posts, goals, groups, activity)
- Moderation panel (flagged goals/posts/users)
- Bug reports management
- User management (view, block/unblock)

## Outputs
- Admin-only views for dashboards and management actions

## Rules
- Admin access only
- Moderation actions are audited
- Blocking a user hides their content from public views
