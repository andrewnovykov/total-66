# US-201: Goal Subscriptions

## User Story
As a registered user,
I want to subscribe to goals I'm interested in,
So that I can follow their progress in my feed.

## Acceptance Criteria
- [ ] AC-1: User can subscribe to public goals
- [ ] AC-2: User can subscribe to friends-only goals (if friends)
- [ ] AC-3: User cannot subscribe to private goals
- [ ] AC-4: Subscribed goal updates appear in user's feed
- [ ] AC-5: User can unsubscribe from goals
- [ ] AC-6: Subscription count shown on goal
- [ ] AC-7: Guests cannot subscribe

- Registered User
