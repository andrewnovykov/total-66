# US-205: User Feed

## User Story
As a registered user,
I want to see a personalized feed,
So that I can follow activity from goals and users I care about.

## Acceptance Criteria
- [ ] AC-1: Feed shows posts from subscribed goals
- [ ] AC-2: Feed ordered by recency
- [ ] AC-3: Feed can be filtered by post type
- [ ] AC-4: Feed is paginated for performance
- [ ] AC-5: Feed updates with new posts
- [ ] AC-6: Feed shows engagement metrics (likes, comments)

## User Types
- Registered User
