# US-610: Top Goal Setters

## User Story
As a user,
I want to see top goal setters and most active users,
So that I can follow disciplined and consistent creators.

## Acceptance Criteria
- [ ] AC-1: Top goal setters section on People page
- [ ] AC-2: Shows users with strong consistency
- [ ] AC-3: Display avatar, name, level, goals count
- [ ] AC-4: Show active streak indicator
- [ ] AC-5: View profile action available
- [ ] AC-6: Follow action for logged-in users

## User Types
- Guest (view only)
- Registered User

## Priority
Low
