# Feature 22: Gamification (XP + Levels)

## User Story
“As a user, I want to earn XP and levels so I feel rewarded for consistency.”

## Inputs
- Activity events (posts, goal completions, challenge completions, etc.)

## Outputs
- XP gained per activity
- Level progression with badges

## Rules
- XP values are defined in a central table
- Level penalties on failure (if enabled)
- Minimum level is 1
