# US-505: Participant Goal Instance

## User Story
As a participant,
I want to receive my own goal instance from a group goal,
So that I can track my personal progress.

## Acceptance Criteria
- [ ] AC-1: Participant sees goal in "My Goals" after start
- [ ] AC-2: Goal instance has all phases and steps from template
- [ ] AC-3: Participant can complete steps
- [ ] AC-4: Participant can create posts/updates
- [ ] AC-5: Participant cannot edit template structure
- [ ] AC-6: Goal counts toward 3-item active limit
- [ ] AC-7: Progress is tracked individually

## User Types
- Registered User (Participant)

## Priority
High
