# US-612: Social Feed

## User Story
As a registered user,
I want a feed of updates from people and goals I follow,
So that I can stay engaged with my network's progress.

## Acceptance Criteria
- [ ] AC-1: Feed shows updates from followed users
- [ ] AC-2: Feed shows updates from followed goals
- [ ] AC-3: Feed shows updates from followed groups
- [ ] AC-4: Feed respects visibility and friendship rules
- [ ] AC-5: Feed items include: new goals, milestones, posts, completions
- [ ] AC-6: Pagination or infinite scroll
- [ ] AC-7: Filter by post type (optional)

## User Types
- Registered User
