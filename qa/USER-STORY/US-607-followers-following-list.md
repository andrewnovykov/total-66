# US-607: Followers and Following Lists

## User Story
As a registered user,
I want to view my followers and following lists,
So that I can manage my social connections.

## Acceptance Criteria
- [ ] AC-1: User can view list of their followers
- [ ] AC-2: User can view list of users they follow
- [ ] AC-3: Lists accessible from profile page
- [ ] AC-4: Each entry shows user card with follow/friend actions
- [ ] AC-5: Can follow/unfollow directly from list
- [ ] AC-6: Lists support pagination

## User Types
- Registered User
