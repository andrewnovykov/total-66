# US-304: Spam Reporting

## User Story
As a registered user,
I want to report spam or inappropriate content,
So that I can help keep the platform clean.

## Acceptance Criteria
- [ ] AC-1: User can report goals via red flag icon
- [ ] AC-2: User can report posts via red flag icon
- [ ] AC-3: Report modal shows reason options
- [ ] AC-4: User cannot report same item twice
- [ ] AC-5: Items with 3+ reports auto-hidden
- [ ] AC-6: Reported items sent to moderation queue

## User Types
- Registered User
