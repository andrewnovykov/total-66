# US-608: Friends List

## User Story
As a registered user,
I want to view and manage my friends list,
So that I can see my trusted connections and manage them.

## Acceptance Criteria
- [ ] AC-1: User can view list of their friends
- [ ] AC-2: Friends count displayed on profile
- [ ] AC-3: Each entry shows user card with actions
- [ ] AC-4: Can remove friend directly from list
- [ ] AC-5: Can view pending friend requests
- [ ] AC-6: List supports search and pagination

## User Types
- Registered User

## Priority
Medium
