# US-302: Admin Content Moderation

## User Story
As an admin,
I want to review and moderate flagged content,
So that I can maintain a safe and spam-free platform.

## Acceptance Criteria
- [ ] AC-1: Admin can view flagged goals queue
- [ ] AC-2: Admin can view flagged posts queue
- [ ] AC-3: Admin can approve content (remove flag)
- [ ] AC-4: Admin can confirm spam (keep hidden)
- [ ] AC-5: Admin can permanently delete content
- [ ] AC-6: Moderation actions are logged
- [ ] AC-7: Content with 3+ reports auto-flagged

- Admin
