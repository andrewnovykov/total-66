# US-303: Admin Analytics Dashboard

## User Story
As an admin,
I want to view platform analytics,
So that I can understand usage and growth trends.

## Acceptance Criteria
- [ ] AC-1: Dashboard shows total users count
- [ ] AC-2: Dashboard shows total goals count
- [ ] AC-3: Dashboard shows total posts count
- [ ] AC-4: Dashboard shows active users (30 days)
- [ ] AC-5: Dashboard shows new signups (daily/weekly/monthly)
- [ ] AC-6: Charts visualize trends
- [ ] AC-7: Real-time updates for metrics
