# US-004: Profile Management

## User Story
As a registered user,
I want to view and edit my profile information,
So that I can customize how others see me on the platform.

## Acceptance Criteria
- [ ] AC-1: User can view their profile page
- [ ] AC-2: User can edit their username
- [ ] AC-3: User can update their bio/about section
- [ ] AC-4: User can upload/change profile photo
- [ ] AC-5: User can update their password
- [ ] AC-6: Changes are saved and reflected immediately

## User Types
- Registered User

## Priority
Medium
